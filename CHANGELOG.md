# Changelog

All notable changes to auditmyvisitors are listed here. auditmyvisitors follows
[Semantic Versioning](https://semver.org/): while in 0.x, a minor version may contain breaking changes.

## [Unreleased]

### Added

- **Releases:** every release ships a `SHA256SUMS` file and a signed build provenance attestation, and the installer verifies the download against it. Details: [Installation](https://github.com/casoon/auditmyvisitors#installation).
### Changed

- **Pages:** the project site uses the current shared theme (0.12.10).
- **Pages:** the start page shows a "Works with" band for GA4 and Search Console, a release teaser,
  an FAQ and a closing link to the quickstart, and the footer follows the page language (theme 0.12.3).
