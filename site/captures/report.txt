Generate reports

Usage: auditmyvisitors report [OPTIONS] <COMMAND>

Commands:
  overview       Overall traffic overview for a time range
  top-pages      Top pages ranked by sessions
  page           Detailed report for a single URL
  compare        Before/after comparison around a change date
  opportunities  Prioritised opportunities for traffic growth
  queries        Query-level search performance analysis
  ai-traffic     AI referral traffic breakdown
  channels       Traffic channel breakdown with engagement metrics
  clusters       Topic cluster analysis across pages and queries
  decay          Content decay detection — pages losing search performance
  devices        Traffic by device category (desktop, mobile, tablet)
  countries      Traffic by country
  help           Print this message or the help of the given subcommand(s)

Options:
      --verbose  Enable verbose logging
  -h, --help     Print help
